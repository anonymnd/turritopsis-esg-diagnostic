# ESG App Planning Pack

This folder prepares the Turritopsis ESG scoring application before rebuilding the production UI.

## Files

- [visual-research.md](visual-research.md) - Turritopsis screenshots, palette, typography, layout cues, and template options.
- [score-system-simple.md](score-system-simple.md) - Very simple explanation of the scoring system.
- [application-architecture-mvp.md](application-architecture-mvp.md) - MVP scope, pages, roles, data model, and release slices.
- [questionnaire-logic.md](questionnaire-logic.md) - Structure and logic behind the ESG questionnaire.
- [international-benchmark.md](international-benchmark.md) - Lessons from international ESG/sustainability questionnaires.
- [ai-integration-strategy.md](ai-integration-strategy.md) - Where AI should be used, what it should not decide alone, and implementation phases.
